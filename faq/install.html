어떤 PC에 깔아요?

덴트웹을 쓰는 치과의 Windows 데스크 PC에 깔아요. 맥(Mac)이나 태블릿용은 따로 없어요.

얼마나 걸려요?

명령어 한 줄을 붙여 넣으면 1~2분이면 설치가 끝나요. 따로 기사님이 오시지 않아도 데스크에서 직접 할 수 있어요.

준비물은요?

라이센스 키 하나예요. 카카오톡 「데스크알리미 문의방」에 치과 이름·담당자·전화번호를 남기면 받을 수 있어요.

순서를 알려 주세요

  1. 설치 안내 페이지에서 [명령어 복사]
  2. 키보드 ⊞ + R → cmd → Enter
  3. 검은 창에 Ctrl + V → Enter (설치 파일이 저절로 내려와요)
  4. 「설치 끝」 뒤 초기 설정 창에서 안내를 읽고 체크·서명 → [확인]
  5. 라이센스 키를 붙여 넣고 [등록]
  6. [스크립트 받기] → [지금 실행] → 권한 창 [예]
  7. 화면 오른쪽 아래에 막대가 뜨면 끝

다음부터는 컴퓨터를 켜면 저절로 떠요.

파란 「PC 보호」 창이 떠요. 괜찮아요?

처음 깔 때 늘 뜨는 Windows 안내예요. [추가 정보] → [실행]을 누르면 돼요. 「변경을 허용할까요?」 창은 [예]를 누르세요.

이미 깔려 있는데 새 판이 나오면요?

새 판은 저절로 바뀌어요. 쓰던 설정은 지워지지 않아요. 판마다 무엇이 좋아졌는지는 「소식」에 올려요.

설치하다 막히면요?

화면을 사진 찍어 카카오톡 1:1 상담방에 보내 주세요. 그 밖에 궁금한 것은 포프리즘에 문의해 주세요.
